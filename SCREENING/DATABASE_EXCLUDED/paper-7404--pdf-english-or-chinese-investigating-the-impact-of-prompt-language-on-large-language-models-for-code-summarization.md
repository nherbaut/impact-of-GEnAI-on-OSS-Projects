  title: '[PDF] English or Chinese? Investigating the Impact of Prompt Language on Large Language Models for Code Summarization'
  authors: Yijia Tang, Zhiqiu Huang, Jian Xie, Yaoshen Yu, Bowei Xia, Enya Shen, Yukun Cao
  abstract: 'With the rapid advancement of Large Language Models (LLMs) and prompt engineering, intelligent tools for code
    generation and understanding have become deeply integrated into modern software development workflows. In practice, developers
    typically craft natural language prompts to guide LLMs in generating code or summaries. However, developers from different
    linguistic backgrounds often prefer different prompt languages, raising a critical yet underexplored question: Does the
    choice of prompt language affect LLM performance in software engineering tasks? To address this question, this work presents
    the first systematic investigation of the impact of prompt language on method-level code summarization from a multilingual
    perspective. We focus on English and Chinese, evaluating 22 open-source LLMs across three mainstream programming languages
    (Python, Java, and C) using 35 prompt strategies that vary in linguistic form and structural design. Our experimental
    results reveal several key findings. 1, prompt language significantly affects LLM summarization performance, providing
    the first empirical evidence of this effect. 2, different models exhibit distinct language preferences, with some performing
    better under Chinese prompts and others more effectively with English prompts. 3, model size does not correlate linearly
    with performance, medium- and small-sized models sometimes outperform larger ones. 4, cross-lingual prompting introduces
    asymmetric effects, models show varying performance when processing inputs and generating outputs across languages, indicating
    that language transfer mechanisms can influence summary quality. Overall, this study provides new insights and empirical
    evidence for designing prompts in multilingual contexts, offering practical guidance for the effective deployment and
    optimization of LLMs in cross-lingual software engineering tasks.'
