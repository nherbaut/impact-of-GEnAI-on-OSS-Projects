  title: '[PDF] Integrating AI Coding Agents Into Scientific Research'
  authors: Rory Barnes
  abstract: New software tools have emerged that enable AI agents to quickly develop code that analyzes data and generates
    figures, but their mistakes can also harm a researcher's computer, require extensive resources for validation, and cause
    the results to be received more skeptically. These concerns could be mitigated if scientific software is developed in
    a secure environment with a system for monitoring file changes and well-defined standards for handling AI agents. This
    paper first describes how coding agents change eleven aspects of generating, verifying, and reproducing numerical results.
    A six-level scale is then proposed for classifying AI-assisted numerical experiments by their provenance, reproducibility,
    openness, oversight, and falsifiability (PROOF). The scale begins with locally self-consistent, version-controlled, human-verified
    results and culminates in a publicly accessible and curated archive of the files, change history, prompt transcripts,
    independent agent regeneration of the analysis, and multiple cryptographically verifiable attestations of regeneration
    by independent researchers. These aspects of AI-assisted scientific software development have been synthesized into a
    new open source software package called vaibify that optimizes the agentic development of computational experiments ascending
    the PROOF Ladder. Docker containers sequester the agents while a GUI enables researchers to prompt command line agents,
    monitor the current status of local and remote files, and drive a project to PROOF Level 3 (reproducible). The methods
    described in this paper could help researchers reduce the time required to verify agent-written software and efficiently
    communicate trust in AI-assisted science.
